# Standard Operating Procedure & Workflow Guide
## Lab Vault — Sample Logbook & CO₂ Mass Spectrometry Tool

---

## 1. System Overview & Quick Start

**Lab Vault** is a lightweight, desktop application designed for scientific laboratories working on gas adsorption materials (zeolite monoliths, MOFs, porous carbons, amine-functionalized adsorbents). It combines:
1. **Pillar 1: Sample Logbook**: Centralized database of synthesized samples, composition, and physical properties.
2. **Pillar 2: Multi-Characterization Hub**: Unified file repository for multiple analytical techniques per sample (Mass Spectrometry, XRD, BET surface area, Raman, TGA, and PDFs/photos).
3. **Pillar 3: Origin-Style Mass Spectrometry Analysis Tool**: Interactive tool with Simpson peak integration, mouse-draggable ROI boxes, and rigorous physical $CO_2$ adsorption/desorption capacity ($q$ in mmol/g) calculations.

### Launching the Application
Open a terminal in the project directory and run:
```bash
python main.py
```
Or open a specific measurement file directly:
```bash
python main.py "24082026  final zz30 monoliths 1st.asc"
```

## 2. Pillar 1: Sample Logbook (Bitácora de Muestras)

### Step 1: Registering a New Sample
1. Go to the **📋 1. Sample Logbook** tab.
2. Click **➕ New Sample**.
3. Fill in the required metadata:
   - **Sample ID**: Unique identifier (e.g., `ZZ30_01`, `ZZ10_02`, `MOF74_Ni`).
   - **Material Name / Formulation**: Descriptive name (e.g., `ZZ30 Monolith (B6 Zeolite)`).
   - **Operator / Researcher**: Name of the person who prepared/measured the sample.
   - **Assay Date**: Date of synthesis or testing (`YYYY-MM-DD`).
   - **Total Initial Mass ($m_{\text{total}}$)**: Sample weight in grams (e.g., `0.5055 g`).
   - **Water / Binder Loss (% H₂O)**: Percentage of mass lost during activation/drying (e.g., `21.4%`).
     > **Formula**: The dry active mass is automatically computed:
     > $$m_{\text{active}} = m_{\text{total}} \times \left(1 - \frac{\% \text{H}_2\text{O}}{100}\right)$$
   - **Blank Ads Reference ($q_{\text{ref}}$)**: Capacity contribution from blank substrate/monolith in mmol/g (e.g., `0.23 mmol/g`).
   - **Notes**: Synthesis details, calcination temperatures, binder ratios.
4. Click **💾 Save Sample**. The application creates the sample directory structure in the Vault automatically.

### Step 2: Searching & Managing Samples
- **Instant Search**: Type in the `🔍 Search:` box to filter by Sample ID, Material Name, or Operator.
- **Edit**: Select a sample and click **✏️ Edit** to update parameters.
- **Open Directory**: Click **📂 Open Folder** to open the sample's directory in Windows Explorer.
- **Inspect Characterizations**: Double-click any row or click **🔬 View Characterizations ➔** to move directly to Pillar 2.

## 3. Pillar 2: Multi-Characterization Hub

When a sample is selected, the Hub displays an active sample banner with key parameters ($m_{\text{total}}$, active mass, date, operator). You can attach and organize files across analytical techniques:

### Technique Tabs:
1. **🧪 Mass Spectrometry (.asc)**:
   - Click **➕ Attach .asc File** to copy a raw measurement file into the sample vault.
   - Inspect existing files, their analysis status (`Pending` vs `Analyzed`), and calculated capacities ($q_{\text{ads}}$, $q_{\text{des}}$, recovery %).
   - Click **🚀 OPEN IN MASS SPECTROMETRY TOOL** to load the file and sample directly into the analysis engine.
2. **🔬 X-Ray Diffraction (XRD)**:
   - Attach pattern files (`.raw`, `.xy`, `.dat`, `.csv`).
   - Write structural observations in the **Key Observations** box (e.g., crystalline phase purity, peak positions) and click **💾 Save Notes**.
3. **📐 N₂ Physisorption / BET Surface Area**:
   - Attach isotherm files (`.xls`, `.xlsx`, `.csv`).
   - Record key textural parameters:
     - **BET Specific Surface Area** ($S_{\text{BET}}$ in $m^2/g$)
     - **Total Pore Volume** ($cm^3/g$)
     - **Average Pore Diameter** ($nm$)
   - Click **💾 Save BET Parameters**.
4. **💡 Raman Spectroscopy**:
   - Attach spectra (`.txt`, `.csv`, `.spc`) and save band identification notes.
5. **📁 Documents & Reports**:
   - Attach monolith photos, scanning electron microscopy (SEM) images, calibration sheets, or summary PDFs.
   - Double-click or click **📂 Open File** to launch in the default Windows application.

## 4. Pillar 3: Mass Spectrometry & CO₂ Capacity Tool

### Understanding `.asc` Quadrupole Files
Files generated by MID / Residual Gas Analyzers (Pfeiffer, Balzers, etc.) use TSV format with carriage returns (`\r`). The software automatically maps the channels:
- `'0/0'`: $N^+ / N_2^{++}$ ($m/z = 14.13$)
- `'0/1'`: $O^+$ ($m/z = 16.13$)
- `'0/2'`: $H_2O$ ($m/z = 18.16$)
- `'0/3'`: $N_2 / CO$ ($m/z = 28.19$)
- `'0/4'`: $O_2$ ($m/z = 32.22$)
- `'0/5'`: $Ar$ ($m/z = 40.22$)
- `'0/6'`: $CO_2$ ($m/z = 44.28$)

### Step-by-Step Analysis Workflow

#### 1. Configure Channels & Scale (Tab 1: Channels & Plot)
- Check or uncheck gas channels to display. By default, $H_2O$, $N_2/CO$, and $CO_2$ are highlighted.
- Choose Time Unit: **Minutes (min)** or **Seconds (s)**.
- Toggle **Logarithmic Y-Scale** to inspect baseline drift or trace contamination.

#### 2. Set Up Integration Regions (Tab 2: Regions & Integration)
- **Automatic 1-Click Detection**:
  - Click **⚡ AUTO-DETECT CYCLES**. The algorithm detects signal transition thresholds and automatically adds paired Adsorption and Desorption boxes for all cycles.
- **Manual ROI Boxes**:
  - **🟡 + Adsorption Box**: Inserts a yellow band. Mode: `straight_line` (or `avg_ads_baseline`). Computes the net consumption integral below the upper breakthrough baseline:
    $$\text{Area}_{\text{ads}} = \int_{t_1}^{t_2} (y_{\text{baseline}}(t) - y_{\text{gas}}(t)) \, dt$$
  - **🟣 + Desorption Box**: Inserts a pink band. Mode: `horizontal_left` ($y_{\text{base}} = y_1$) to capture the release peak above baseline:
    $$\text{Area}_{\text{des}} = \int_{t_1}^{t_2} (y_{\text{gas}}(t) - y_{\text{baseline}}(t)) \, dt$$
- **Interactive Mouse Dragging**:
  - Click and drag the left edge ($t_1$) or right edge ($t_2$) on the chart to adjust boundaries.
  - Click and drag inside the box to move the entire band along the time axis while keeping $\Delta t$ constant.
- **Fine-Tuning**: 
  - Use the `Start:` and `End:` spinboxes to nudge boundaries by $\pm 0.2$ min.
  - Use the `Δt (min):` spinbox to directly change the cycle duration (automatically updates the end boundary).
  - Check **Lock Δt** to lock the duration so that shifting the `Start` time preserves the exact cycle width ($t_{\text{end}} = t_{\text{start}} + \Delta t$).
Parameters automatically synchronize with the sample metadata:
- **Temperature Correction of Molar Volume**:
  $$V_{m,T} = 24465.0 \times \frac{T(^\circ\text{C}) + 273.15}{298.15} \quad [\text{mL/mol}]$$
- **Total Molar Flow Rate**:
  $$\dot{n}_{\text{total}} = \frac{F_{\text{total}}}{V_{m,T}} \quad [\text{mol/min}]$$
- **Detector Calibration Factor ($k$)**:
  $$k = \frac{C_0}{S_{\text{baseline}}} \quad [\text{A}^{-1}]$$
- **Total Moles Adsorbed / Desorbed**:
  $$n(CO_2) = \dot{n}_{\text{total}} \times k \times \text{Area} \times 1000 \quad [\text{mmol}]$$
- **Net Specific Capacity ($q_{\text{net}}$ in mmol/g)**:
  $$q_{\text{net}} = \frac{n(CO_2)}{m_{\text{active}}} - q_{\text{ref}}$$
- **Desorption Recovery Ratio (%)**:
  $$\text{Recovery} = \frac{q_{\text{net,Des}}}{q_{\text{net,Ads}}} \times 100\%$$

#### 4. Save Analysis & Export (Tab 4: Report)
- Click **💾 SAVE ANALYSIS TO SAMPLE**:
  - Writes `analysis_<filename>.json` inside `data_vault/samples/<sample_id>/mass_spec/analyses/`.
  - Generates `co2_report_<sample_id>.txt` in `reports/`.
  - Updates sample status to `Analyzed` in the Logbook.
- Click **📋 Copy Report** to copy formatted summary tables directly to your clipboard.
- Click **🖼️ Export PNG/PDF** on the chart toolbar to save publication-quality 300 DPI figures, vector SVGs, or PDFs.

## 5. Data Vault Architecture & Portability

All files are structured locally inside the `data_vault/` directory:
```text
data_vault/
├── samples_logbook.json        # Central sample database
└── samples/
    └── ZZ30_01/
        ├── metadata.json       # Sample metadata & parameter history
        ├── mass_spec/
        │   ├── raw_data/       # Raw .asc files
        │   ├── analyses/       # Saved ROI boundaries & capacity results
        │   └── reports/        # Textual & CSV reports
        ├── xrd/                # XRD patterns & notes
        ├── bet/                # BET isotherms & surface area values
        ├── raman/              # Raman spectra
        └── documents/          # Supplementary PDFs, images, notes
```

### Changing the Vault Location:
To move the vault to an external hard drive, shared network folder, or cloud drive (OneDrive, Google Drive, Dropbox):
1. In the top menu, go to **File ➔ Change Vault Directory...**
2. Choose your new folder. The application updates `settings.json` and loads the new vault automatically.

## 6. Troubleshooting & FAQs

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **No plot lines visible** | All gas channels are unchecked. | In Tab 1, check at least one gas channel or click `Select All`. |
| **Area reads 0.00** | Start time is greater than end time, or region is outside data range. | Check Start and End boundaries in the Fine-Tuning box. |
| **Auto-detect finds no cycles** | Low signal-to-noise ratio or non-standard baseline. | Add boxes manually using `+ Adsorption` and `+ Desorption`, then drag into position. |
| **Chart looks squished vertically** | Strong concentration peak obscuring baseline. | Toggle **Logarithmic Y-Scale** in Tab 1 or zoom in using the Matplotlib magnifying glass tool. |
| **Reset zoom** | Zoomed in too far. | Click the **Home icon (🏠)** on the Matplotlib toolbar below the chart. |
